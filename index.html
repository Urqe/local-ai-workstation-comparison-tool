Decision readout

This is a planning model, not a benchmark database. Apple source prices use current Finnish Apple Store gross pricing; generic Windows/Linux prices are representative estimates. Hardware and cloud-subscription inputs are stored gross; Net mode removes the selected VAT. The paid-overflow €/M token input is deliberately treated as a net API-equivalent rate: Gross mode adds VAT, Net mode does not. Local electricity models AI-active compute only and excludes ordinary idle/sleep power, because idle behaviour varies too much by device and user; this slightly favours local hardware if a machine is left powered on for long periods. AI power and speed are planning estimates, not vendor specifications. Cloud token-equivalent allowance, tokens/hour and workload presets are planning estimates because subscription limits are not literal monthly token buckets and agentic workloads vary sharply by repository and workflow. Real token/s depends heavily on model architecture, quantization, context, backend, batching and software quality.
