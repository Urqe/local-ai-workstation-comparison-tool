Decision readout

This is a planning model, not a benchmark database. Apple catalog prices are static Finnish Store planning inputs, not live quotes; generic Windows/Linux prices are representative estimates. Hardware and cloud-subscription inputs are stored gross; Net mode removes the fixed Finnish general VAT of 25.5% (Gross mode adds it to the net API-equivalent overflow rate). The paid-overflow €/M token input is deliberately treated as a net API-equivalent rate: Gross mode adds VAT, Net mode does not. Local electricity models AI-active compute only and excludes ordinary idle/sleep power, because idle behaviour varies too much by device and user; this slightly favours local hardware if a machine is left powered on for long periods. AI power is a planning estimate. Generation speed is unverified; memory fit is not proof of equivalent performance or task quality. Cloud token-equivalent allowance, tokens/hour and workload presets are planning estimates because subscription limits are not literal monthly token buckets and agentic workloads vary sharply by repository and workflow. Real token/s depends heavily on model architecture, quantization, context, backend, batching and software quality.
